### Go Programming Language Quiz

**1. Who were the original designers of the Go programming language?**  
A) Guido van Rossum, Bjarne Stroustrup, James Gosling  
B) Robert Griesemer, Rob Pike, Ken Thompson  
C) Dennis Ritchie, Brian Kernighan, Ken Thompson  
D) Anders Hejlsberg, Scott Guthrie, Anders Toxboe  
**Correct answer:** B) Robert Griesemer, Rob Pike, Ken Thompson

---

**2. What was a primary motivation behind the creation of Go?**  
A) To replace Java as the most popular language for web development  
B) To create a language with efficient garbage collection and strong support for concurrent programming  
C) To develop a language specialized for artificial intelligence research  
D) To design a language that compiles directly to machine code without an intermediate representation  
**Correct answer:** B) To create a language with efficient garbage collection and strong support for concurrent programming

---

**3. Which of the following are key features of Go? (Select all that apply)**  
A) Garbage collection  
B) Structural typing  
C) Support for generics (added in Go 1.18)  
D) Multiple inheritance  
**Correct answers:** A) Garbage collection, B) Structural typing, C) Support for generics (added in Go 1.18)

---

**4. Go’s concurrency model is primarily based on which concept?**  
A) Threads and locks  
B) Actors  
C) Goroutines and channels  
D) Events and callbacks  
**Correct answer:** C) Goroutines and channels

---

**5. Which of the following is NOT a design goal of Go?**  
A) Simplicity and clarity in syntax  
B) High-performance computing with manual memory management  
C) Efficient compilation and fast execution  
D) Built-in support for concurrent programming  
**Correct answer:** B) High-performance computing with manual memory management

**6. What type of typing system does Go use?**  
A) Dynamic typing  
B) Static typing  
C) Weak typing  
D) Duck typing  
**Correct answer:** B) Static typing

A) Interfaces in Go require explicit declaration of implementation  
B) Go uses structural typing for interfaces, meaning a type implements an interface by having the required methods

D) Interfaces are used only for error handling in Go  
**Correct answer:** B) Go uses structural typing for interfaces, meaning a type implements an interface by having the required methods

**8. Which of the following are typical use cases for Go? (Select all that apply)**
